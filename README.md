# CID releases

Windows installers for [CID](https://cid.pumpkins.dev), CI/CD that runs on your own computer.

- **Download:** the latest installer is always on the [latest release](https://github.com/MohsenManoochehr/CID-releases/releases/latest).
- **What's new:** see [CHANGELOG.md](CHANGELOG.md), or the notes on each [release](https://github.com/MohsenManoochehr/CID-releases/releases).

CID checks this repository's releases to tell you when an update is available.
